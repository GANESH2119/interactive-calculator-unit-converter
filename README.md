# Interactive Calculator & Unit Converter

## Intern Circle - Task 1

This project is a beginner-friendly Command Line Interface (CLI)
program developed using Python.

## Features

- Basic arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Kilometers to Miles conversion
- Celsius to Fahrenheit conversion
- Input validation using while loops
- Division by zero handling
- Menu-driven interface

## Technologies Used

- Python

## Python Concepts Used

- Variables
- Functions
- Conditional statements
- While loops
- User input
- Exception handling
- Arithmetic operations

## How to Run

Run the following command in the terminal:

```bash
python calculator_converter.py
